Contextual Valuation Radar

현재 주가만 보거나 뉴스만 보는 것이 아니라, 섹터 전체 universe의 각 산업 node 맥락과 현재 가격 위치를 함께 비교해 맥락 대비 저평가/고평가 후보와 초록/노랑/주황/빨강 traffic light를 분류하는 Market Radar 모듈이다.

이제 기준 universe는 M7 중심 watchlist가 아니라 주식 신호등의 카테고리별 글로벌 기업 지도다.

원칙

이 페이지는 투자 추천이 아니다. 목표는 “사라/팔아라”가 아니라 다음 질문에 답하는 것이다.

이 종목의 현재 가격 위치가
해당 node의 기술/사회/정책/시장 맥락과 비교했을 때
과하게 눌려 있는가, 이미 너무 앞서 갔는가, 아니면 판단 보류인가?

입력 데이터

Price

  • 현재가
  • 당일 변동률
  • 52주 고점/저점
  • 52주 range 내 위치
  • 20D / 60D momentum

::

Node Context

  • AI Semiconductor
  • HBM Memory
  • AI Data Center
  • Power Infrastructure
  • Cloud Hyperscaler
  • On-device AI / Robotics / Healthcare AI

::

External Context

  • export control / regulation
  • social risk-off / 지정학
  • AI capex ROI debate
  • 기술/보안 shock
  • market liquidity / risk appetite

::

Evidence

  • high-quality news source
  • earnings / guidance / capex
  • supply-chain data
  • policy / regulation
  • customer adoption signal

::

분류 체계

맥락 대비 저평가 후보

조건 후보:

  • node narrative score가 강하다.
  • 현재가는 52주 range 하단/중단에 있다.
  • 고점 대비 할인폭이 크지만 핵심 thesis가 훼손되지 않았다.
  • 관련 뉴스가 supply/demand/adoption 근거를 보강한다.
  • bear pressure가 일시적이거나 source quality가 낮다.

해석:

가격은 눌려 있는데, 산업/사회/기술 맥락은 아직 살아 있는 후보.
단, 매수 추천이 아니라 더 깊게 볼 후보군이다.

고평가 부담 후보

조건 후보:

  • 현재가가 52주 range 상단에 있다.
  • narrative score가 약하거나 이미 가격이 먼저 반영했다.
  • social/policy risk가 커지고 있다.
  • capex ROI, margin pressure, regulation, export control 같은 반대 근거가 증가한다.

해석:

맥락보다 가격이 앞서갔을 수 있는 후보.
좋은 회사여도 valuation 부담은 따로 표시한다.

하락 재평가 후보

조건 후보:

  • 20D/60D momentum이 약하다.
  • bear/news risk가 동시에 증가한다.
  • 기존 node thesis가 훼손되는 근거가 있다.
  • 시장상황이 risk-off로 바뀐다.

해석:

단순 조정인지 thesis 변화인지 확인해야 하는 후보.

판단 보류 / 정가치권

조건 후보:

  • 가격 위치와 맥락 점수가 서로 애매하다.
  • 현재가와 narrative가 대체로 같이 움직인다.
  • 근거가 부족하거나 social context가 혼재돼 있다.

종목-노드 연결

  • NVIDIA / AMD / TSMC: AI Semiconductor, AI Data Center, Advanced Packaging
  • Samsung Electronics / SK Hynix: HBM Memory, On-device AI
  • Microsoft / Alphabet / Amazon: Cloud Hyperscaler, AI Data Center, Capex ROI
  • Vertiv / Eaton / NuScale Power: Power Infrastructure, Grid/Cooling/Nuclear bottleneck

사회적 맥락 입력

Daily Market Brief는 다음 context keyword를 별도 집계한다.

  • regulation/export: export, restriction, ban, China, tariff, control, regulation
  • security/technology shock: exploit, hack, outage, chain, custody, failure
  • social risk-off: war, conflict, election, geopolitical, panic
  • AI adoption/capex debate: capex, ROI, spending, investment, data center, hyperscaler

운영 방식

수집: 현재가 + 뉴스 + node queries
분석: price position + node narrative + social context
분류: 저평가 후보 / 고평가 부담 / 하락 재평가 / 판단 보류
출력: Daily Market Brief + Market Ontology page
검토: human review 후 ontology/prediction ledger 승격

주의

  • P/E, EV/EBITDA, FCF yield 같은 fundamental valuation은 아직 자동화하지 않았다.
  • 현재 분류는 contextual relative valuation 후보이지 절대가치 산정이 아니다.
  • 가격 데이터 provider 장애 시 fallback을 쓰고, source를 반드시 기록한다.
  • 잘못된 후보도 삭제하지 않고 prediction/valuation review에 남긴다.
