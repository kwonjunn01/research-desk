0. 현재 시장 내러티브

SK하이닉스의 핵심 논점은 HBM 리더십 자체가 아니라 HBM premium mix가 얼마나 오래 유지되고, 범용 DRAM 업사이클이 EPS revision으로 실제 전환되는지다. 최근 공개 뉴스 흐름은 1Q26 record profit, memory price 상승, HBM 수요가 공급을 초과한다는 방향으로 강하지만, 주가 premium도 이미 상당 부분 이를 반영했을 수 있어 price reflection과 consensus revision을 분리해야 한다.

0-1. 시장이 이미 믿는 것

시장은 NVIDIA 공급망, HBM3E/HBM4 선점, AI 메모리 부족을 이미 강하게 믿는다. 새 alpha는 “HBM 수요가 좋다”가 아니라 ① HBM share 방어, ② premium margin 유지, ③ DRAM ASP/bit shipment 동반 개선, ④ CAPEX discipline과 wafer shortage가 공급과잉으로 바뀌지 않는지에서 나온다.

1. 사업모델 / 역할

HBM/DRAM/NAND 메모리 공급 모델. HBM은 premium mix와 고객 allocation을 통해 이익률을 끌어올리고, 범용 DRAM은 cycle base earnings를 만든다. CAPEX discipline이 깨지면 다음 cycle 공급과잉 리스크가 커진다.

2. 기대치/수요·비용·병목 전파

AI accelerator 출하 → HBM attach 확대 → HBM ASP·mix·share → memory margin premium → EPS revision으로 전파된다. 동시에 서버/PC DRAM 회복 → DRAM ASP·bit shipment → base earnings 개선 경로를 따로 봐야 한다.

3. 돈이 들어오는 단위

돈이 들어오는 경로는 네 갈래다: HBM 매출 비중·ASP·margin, 범용 DRAM ASP·bit shipment, AI 고객 allocation/장기공급, 그리고 CAPEX discipline으로 cycle premium을 지키는 경로. 공개 기사 제목보다 실적콜의 HBM 매출 비중, 고객 allocation, wafer capacity, DRAM 가격·출하 코멘트가 우선이다.

HBM revenue share, HBM margin, DRAM ASP, bit shipment, customer allocation, wafer capacity, capex guidance, trailing/forward EPS proxy, consensus revision history
4. 인정 가능한 근거
  • 회사별 thesis registry 있음: generic category fallback 아님
  • 직접 뉴스/리포트 6건이 오늘 맥락과 연결됨
  • CAPEX 노출 점수가 높아 AI data-center 투자 언어와 연결 가능
  • 수요 점수가 높아 주문/사용률/매출 전환 확인 가치가 큼
5. Bull case
  • HBM demand가 공급을 계속 초과하고 premium margin이 유지된다.
  • DRAM ASP와 bit shipment가 동시에 개선되어 HBM 외 base earnings도 올라간다.
  • CAPEX discipline이 유지되어 다음 cycle 공급과잉 우려가 늦춰진다.
6. 핵심 논쟁 / Bear case
  • 현재 valuation premium이 HBM 리더십을 이미 과도하게 반영했는데 EPS revision이 따라오지 않는다.
  • 삼성전자/Micron의 HBM catch-up 또는 고객 가격 협상으로 premium margin이 낮아진다.
  • wafer/capex 확대가 중기 공급과잉 또는 cycle peak 우려로 바뀐다.
7. 다음 검증 / 반증 조건
  • 다음 실적/IR에서 HBM 매출 비중, margin, 고객 allocation이 기존 기대보다 개선되는가
  • DRAM ASP/bit shipment와 재고일수가 EPS proxy/consensus와 같은 방향으로 움직이는가
  • 20D/60D/52W 가격반영도가 EPS revision보다 앞서 있는지 확인
  • TrendForce/DRAMeXchange 등 industry source에서 HBM4/wafer shortage가 실제 공급 제약인지 headline noise인지 재검증
  • HBM 수요 headline은 강하지만 margin·shipment·share 숫자가 개선되지 않는다.
  • forward EPS proxy 또는 공개 consensus 요약이 하향/정체되는 동안 주가만 상단권에 머문다.
  • 고객 다변화 없이 단일 고객·가격 협상 리스크가 커진다.
  • CAPEX 확대가 discipline이 아니라 다음 공급과잉 신호로 해석된다.
