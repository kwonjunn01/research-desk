20초 결론

결론: AMD는 AI GPU challenger narrative가 아니라 Data Center 매출·Q2 guidance·MI450/Helios ramp가 EPS/FCF revision으로 이어지는지 확인해야 한다. 근거: AMD IR earnings release/slides/transcript 경로를 확인했고, public proxy 가격·valuation·EPS cache를 재갱신했다. 리스크: NVIDIA lock-in, MI450 margin dilution, gaming/China drag, 고객 forecast의 매출 전환 실패. 다음 확인: Data Center 성장률, gross margin, MI450 고객 물량, 30–90일 sell-side EPS/FCF revision. 판단 상태: 증권사/컨센서스 검토 미완료 · 판단 보류.

0. 현재 시장 내러티브

AMD는 AI 가속기 challenger로서 “GPU 대안” narrative만으로는 부족하다. 이번 source-pack 기준 핵심은 Data Center가 실제 매출/이익 성장의 중심으로 이동했는지, MI450/Helios 고객 forecast와 대규모 deployment pipeline이 2026년 서버 성장·gross margin·EPS proxy로 이어지는지다. NVIDIA 대비 share catch-up은 아직 검증 대상이며, 강한 결론은 sell-side revision history와 고객별 물량 확인 전까지 보류한다.

0-1. 시장이 이미 믿는 것

시장은 AMD가 AI accelerator에서 NVIDIA 대체/보완 공급자가 될 가능성을 이미 반영한다. 새 alpha는 “AI 수요가 강하다”가 아니라 Q2 2026 가이던스, Data Center mix, non-GAAP gross margin, MI450/Helios 고객 forecast가 기존 consensus보다 상향되는지에서 나온다. 반대로 고객 pipeline이 headline에 그치거나 margin이 희석되면 기대과열로 분류한다.

0-2. 병목-first 판정

시나리오별 병목 확인 필요 · Tier 확인 필요 · narrative beta 강등 가능. 회사는 고정 리스트가 아니라 이 active scenario에서 병목 해결력이 있을 때만 후보가 된다.

1. 사업모델 / 역할

AMD는 Data Center CPU/GPU, Client, Gaming, Embedded로 나뉜다. AI upside는 Instinct/MI 시리즈와 서버 CPU attach에서 나오지만, 전체 EPS는 client 회복, embedded/gaming cycle, 공급능력, gross margin, R&D/opex 레버리지까지 같이 봐야 한다.

2. 기대치/수요·비용·병목 전파

Agentic/inference workload 증가 → hyperscaler·enterprise accelerator 수요 → AMD MI/Helios 공급 확대와 서버 CPU attach → Data Center 매출 mix 및 gross margin → EPS/consensus revision → 가격반영도 검증으로 전파된다. 단, NVIDIA ecosystem lock-in과 software stack 성숙도는 전파를 지연시킬 수 있다.

3. 돈이 들어오는 단위

돈이 들어오는 경로는 (1) Data Center GPU/accelerator shipment와 ASP, (2) EPYC/server CPU attach, (3) MI450/Helios 고객 forecast가 실제 주문/매출로 전환되는 경로, (4) non-GAAP gross margin과 opex leverage, (5) client 회복이 AI 투자비 부담을 흡수하는 경로다.

Data Center revenue, accelerator shipment/ASP, MI450/Helios customer forecast, server CPU attach, Q2 revenue guidance, non-GAAP gross margin, diluted EPS, forward EPS proxy, consensus revision history
4. 인정 가능한 근거
  • 회사별 thesis registry 있음: generic category fallback 아님
  • 직접 뉴스/리포트 6건이 오늘 맥락과 연결됨
  • CAPEX 노출 점수가 높아 AI data-center 투자 언어와 연결 가능
  • 수요 점수가 높아 주문/사용률/매출 전환 확인 가치가 큼
5. Bull case
  • Q2 2026 revenue guide와 non-GAAP gross margin이 Data Center mix 개선과 함께 consensus 상향으로 이어진다.
  • MI450/Helios 고객 forecast가 실제 deployment/order visibility로 전환되어 NVIDIA 보완 공급자 지위가 강화된다.
  • server CPU attach와 client 회복이 AI GPU 투자비를 흡수해 EPS leverage가 커진다.
6. 핵심 논쟁 / Bear case
  • AI accelerator pipeline은 강하지만 NVIDIA ecosystem lock-in과 software gap 때문에 shipment/share 전환이 기대보다 느리다.
  • 높아진 기대가 이미 주가에 반영된 상태에서 Q2/Q3 guide가 추가 상향되지 않거나 gross margin이 희석된다.
  • Data Center 외 client/gaming/embedded cycle이 흔들리면 AI narrative가 전체 EPS를 충분히 끌어올리지 못한다.
7. 다음 검증 / 반증 조건
  • Q2 2026 실제 매출이 회사 guide midpoint $11.2B 및 non-GAAP gross margin 약 56%를 넘는지 확인
  • MI450/Helios 관련 고객 forecast가 order/backlog/shipment 숫자로 전환되는지 확인
  • Data Center segment 매출·영업이익과 forward EPS proxy가 같은 방향으로 상향되는지 확인
  • ROCm/software ecosystem adoption과 hyperscaler reference가 NVIDIA lock-in을 얼마나 줄이는지 확인
  • Q2/Q3 guide가 상향되지 않거나 Data Center 성장률이 headline 대비 둔화된다.
  • MI450/Helios forecast가 실제 고객 주문/출하로 연결되지 않는다.
  • gross margin 또는 opex leverage가 약해 revenue growth가 EPS revision으로 전환되지 않는다.
  • CUDA/ecosystem inertia 때문에 AMD accelerator adoption이 보완 공급 수준에 머문다.

  • forward EPS proxy는 public snapshot이며 paid/verified consensus time-series가 아니다.
