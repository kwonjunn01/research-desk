ANALYST MEMO · business-first강한 관찰 후보Samsung Electronics (005930.KS) · HBM Memory / HBM / Memory / Storage에서 HBM/DRAM/NAND/foundry/device AI 포지션
0. 현재 시장 내러티브

현재 삼성전자 강세를 'AI 서버 수요 → DRAM/NAND 가격 상승' 한 줄로 설명하면 틀릴 가능성이 크다. 더 정확한 base case는 ① 메모리 업사이클 기대가 이미 상당 부분 가격에 반영된 상태에서, ② 범용 DRAM/DDR5 가격·bit shipment·재고 정상화가 DS 이익을 얼마나 실제로 끌어올리는지, ③ HBM은 qualification 뉴스 자체보다 shipment/yield/share 회복이 숫자로 확인되는지, ④ foundry/System LSI 적자와 MX/모바일 기여가 메모리 개선을 얼마나 희석하는지를 분리해서 보는 것이다.

0-1. 시장이 이미 믿는 것

시장은 이미 메모리 가격 회복, DS 영업 레버리지, HBM catch-up 가능성, 외국인/기관 수급 유입을 상당히 믿고 있다. 새 alpha는 '좋은 업황'이 아니라 consensus revision이다: DRAM ASP·bit growth·DS margin·HBM shipment/yield·foundry 적자폭 중 어느 항목이 기존 기대보다 더 좋아지거나 나빠지는지가 핵심이다.

1. 사업모델 / 역할

삼성전자는 메모리(DS Memory)가 이익 변동의 핵심이지만, 전체 주가는 메모리만으로 결정되지 않는다. DRAM/NAND/HBM의 ASP·bit shipment·mix가 DS 이익을 만들고, foundry/System LSI 적자, MX 스마트폰/AI폰 mix, 환율·자본환원·외국인 수급이 multiple과 할인율을 조정한다.

2. 기대치/수요·비용·병목 전파

관찰 경로는 '수요가 있다'가 아니라 '기대치가 올라가는가'다. 서버/AI/일반 IT 수요 → DRAM/DDR5/HBM 물량·가격·mix → DS 영업이익률과 현금흐름 → consensus EPS revision → 외국인/기관 수급과 valuation re-rating으로 전파된다. HBM은 고객 인증 제목보다 실제 공급 물량·수율·share와 premium margin이 확인될 때만 upside로 본다.

3. 돈이 들어오는 단위

돈이 들어오는 경로는 네 갈래다: (1) 범용 DRAM/DDR5 ASP와 bit growth가 DS Memory margin을 올리는 경로, (2) HBM3E/HBM4 shipment·yield·share 회복이 premium mix를 만드는 경로, (3) foundry/System LSI 적자 축소가 메모리 이익을 덜 깎아먹는 경로, (4) MX/모바일·자본환원·외국인 수급이 multiple discount를 줄이는 경로. 이 중 하나라도 숫자로 확인되지 않으면 단순 AI 수혜로 결론내리지 않는다.

DRAM/DDR5 ASP, DRAM bit shipment, DS Memory operating profit/margin, HBM shipment/yield/share/revenue mix, foundry/System LSI loss, MX margin, EPS revision, foreign/institutional net buying
4. 인정 가능한 근거
  • 회사별 thesis registry 있음: generic category fallback 아님
  • 직접 뉴스/리포트 6건이 오늘 맥락과 연결됨
  • CAPEX 노출 점수가 높아 AI data-center 투자 언어와 연결 가능
  • 수요 점수가 높아 주문/사용률/매출 전환 확인 가치가 큼
5. Bull case
  • DRAM/DDR5 ASP와 bit shipment가 동시에 개선되고 DS Memory margin이 consensus보다 빠르게 회복된다.
  • HBM이 qualification headline을 넘어 실제 shipment/yield/share 회복으로 확인되어 SK하이닉스 대비 discount가 축소된다.
  • Foundry/System LSI 적자 축소와 MX margin 방어가 메모리 이익 개선을 희석하지 않는다.
6. 핵심 논쟁 / Bear case
  • 현재 주가는 메모리 회복을 이미 상당 부분 반영했는데, DS margin/EPS revision이 기대만큼 올라오지 않는다.
  • HBM에서 실제 공급량·수율·share 개선이 확인되지 않아 AI premium이 제한되고 SK하이닉스와의 gap이 유지된다.
  • Foundry/System LSI 적자, NAND 회복 지연, 환율/정책/중국 수요 리스크가 DRAM 업사이클 효과를 희석한다.
7. 다음 검증 / 반증 조건
  • 다음 실적/IR에서 DS Memory 영업이익률, DRAM ASP/bit growth, 재고일수가 기존 기대보다 개선되는가
  • HBM 관련 뉴스가 qualification 제목이 아니라 shipment/yield/share/revenue mix 숫자로 바뀌는가
  • Foundry/System LSI 적자폭과 3nm/2nm 고객 확보가 실제로 개선되는가
  • 외국인/기관 수급과 EPS consensus revision이 같은 방향으로 움직이는가
  • DRAM ASP 상승이 둔화되거나 bit shipment/재고 정상화가 동반되지 않는다.
  • HBM 공급량·수율·share가 확인되지 않고 AI premium 기대만 남는다.
  • Foundry/System LSI 적자와 MX/환율/정책 리스크가 DS 개선분을 상쇄한다.
  • 주가는 상단권인데 EPS revision이 따라오지 않아 가격반영 부담이 커진다.
