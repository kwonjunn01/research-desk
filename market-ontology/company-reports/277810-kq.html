20초 결론

결론: Rainbow Robotics는 로봇/휴머노이드 narrative는 강하지만, 삼성 관계·기술 기대가 실제 unit shipment·ASP·서비스 매출로 바뀌기 전에는 speculative/provisional로 둔다. 근거: 52W 73.3%, drawdown -19.9%, 20D 28.3%, 60D 16.1%; PER 10,205, Forward PER 확인 필요, PBR 107.99, ROE 1.1%, OPM 13.1%; trailing EPS 73, forward EPS proxy 확인 필요, forward PE 확인 필요. 리스크: 기술/삼성 narrative가 가격을 먼저 끌어올렸지만 실제 출하·마진·EPS가 따라오지 않는다. 다음 확인: unit shipment, ASP, backlog/order, gross margin, repeat/service revenue, 30–90일 EPS/OP revision history. 판단 상태: 증권사/컨센서스 검토 미완료 · 판단 보류.

0. 현재 시장 내러티브

Rainbow Robotics: 로봇/휴머노이드 narrative는 강하지만, 삼성 관계·기술 기대가 실제 unit shipment·ASP·서비스 매출로 바뀌기 전에는 speculative/provisional로 둔다. 현재 public price proxy는 52W 73.3%, drawdown -19.9%, 20D 28.3%, 60D 16.1%이고, public fundamentals snapshot은 PER 10,205, Forward PER 확인 필요, PBR 107.99, ROE 1.1%, OPM 13.1%이다. 이 수치는 관찰용이며 DART/IR/증권사 원문 검증 전 reviewed 판단으로 쓰지 않는다.

0-1. 시장이 이미 믿는 것

시장은 삼성전자 지분/협력, 휴머노이드 로봇, 산업 자동화 기대를 빠르게 가격에 반영할 수 있다. 새 alpha는 실제 공급계약, 출하량, ASP, gross margin, 반복 매출이 확인되는지다. verified 30–90일 sell-side revision history는 아직 연결되지 않았으므로 판단 보류를 유지한다.

0-2. 병목-first 판정

시나리오별 병목 확인 필요 · Tier 확인 필요 · narrative beta 강등 가능. 회사는 고정 리스트가 아니라 이 active scenario에서 병목 해결력이 있을 때만 후보가 된다.

1. 사업모델 / 역할

협동/휴머노이드/산업용 로봇 기술과 제품화를 가진 edge robotics 기업이다. 기술 데모가 아니라 납품·수율·원가·서비스 매출로 번역될 때 의미가 생긴다.

2. 기대치/수요·비용·병목 전파

로봇/physical AI 관심 → 고객 PoC/자동화 예산 → 로봇 unit shipment·ASP·서비스 attach → margin/EPS revision → 가격반영도로 전파되는지 확인한다.

3. 돈이 들어오는 단위

robot unit shipment, ASP, customer orders/backlog, service/software attach, gross margin, Samsung-linked commercialization evidence

unit shipment, ASP, backlog/order, gross margin, repeat/service revenue, 30–90일 EPS/OP revision history
4. 인정 가능한 근거
  • 회사별 thesis registry 있음: generic category fallback 아님
  • 오늘 직접 뉴스 근거는 부족해 category/slow cache 중심으로만 관찰
  • 마진 snapshot 보유: 내러티브가 이익으로 번역되는지 볼 수 있음
5. Bull case
  • 삼성/산업 고객 발주가 unit shipment·ASP·margin으로 확인되고, 로봇 매출/수주 revision이 가격보다 빠르게 올라온다.
  • public proxy가 아니라 증권사/컨센서스/IR 원문에서 같은 방향의 근거가 2개 이상 확인된다.
6. 핵심 논쟁 / Bear case
  • 기술/삼성 narrative가 가격을 먼저 끌어올렸지만 실제 출하·마진·EPS가 따라오지 않는다.
  • 가격/valuation proxy가 먼저 움직였지만 verified EPS/OP/FCF revision이 따라오지 않는다.
  • company-specific evidence가 부족해 sector beta를 개별 회사 alpha로 과잉 번역한다.
7. 다음 검증 / 반증 조건
  • unit shipment, ASP, backlog/order, gross margin, repeat/service revenue, 30–90일 EPS/OP revision history
  • 최근 공개 증권사/리서치 하우스 preview/review 2건 이상에서 EPS/OP/target rationale 방향 확인
  • DART/IR/실적콜 원문에서 segment·수주·margin 숫자 추출
  • 가격 20D/60D/52W 위치와 revision direction이 같은 방향인지 비교
  • 공급계약/출하량/마진이 확인되지 않거나 EPS/OP revision 없이 테마성 momentum만 지속된다.
  • 핵심 매출 단위가 다음 실적/IR에서 확인되지 않거나 margin이 악화된다.
  • 30–90일 consensus revision이 정체/하향인데 가격만 선반영된다.
