0. 2026-05-29 Weekly QA 반영

이번 주 QA는 기준 registry 수치(16 theme · 38 node · 56 edge · 11 query seed)를 유지하면서, 2026-05-23~29 AI/Market/Cross/Monthly reports에서 확인된 evidence 후보를 기존 node/edge에 연결했다. 아래 항목은 투자 추천이 아니라 dashboard 보강 후보 / source review queue다. 기업명과 ticker는 산업 매핑 참고용이며 매수·매도 판단이 아니다.

새로 연결된 evidence 후보

  • CPO 광통신 · 광트랜시버 · AI 네트워크 스위치: COHR/LITE monthly reports와 value-chain discovery에서 800G/1.6T, optical interconnect, silicon photonics/InP laser, CPO/NPO, 한국 광통신/CPO 직접 노출 후보가 반복 → cpo, optical_transceiver, switch_chip, fiber_material, datacenter_build에 연결 후보.
  • Grid/EPC/load-center · DC 전력 인프라 · 변압기/송전: AI DC 전력 병목이 utility EPC, interconnect, substation, permitting, craft labor, backlog conversion으로 확장 → dc_power, transformer, grid_cable, datacenter_build, hyperscaler에 연결 후보.
  • Agent workload → memory/server/power 병목: π-Bench, ACC, Full Attention, Gamma-World, MemTrace 등 long-horizon agent, memory/KV/context cache, inference cost 신호 → ai_agent, frontier_llm, opensource_llm, training_data, hbm, datacenter_build, dc_power에 연결 후보.
  • Arm CPU/IP · data-center orchestration 후보 seed: Armv9/Neoverse/CSS, data-center royalty, edge/mobile inference 신호 → 기존 custom_asic, on_device, hyperscaler, datacenter_build 주변 ai_cpu_ip 후보 seed로 추적. 회사-primary narrative 비중이 커서 정식 node 승격은 보류.
  • Robotics · On-device AI · Edge demand: embodied VLM, multi-agent world model, on-device/edge inference topic heat → on_device, humanoid, autonomous, korean_ai_chip, opensource_llm에 연결 후보. 실제 deployment·반복 주문 확인 전까지 hype와 분리.
