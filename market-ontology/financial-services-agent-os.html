Financial Services Agent OS

ANTHROPIC FINANCIAL SERVICES → RESEARCH DESK

증권사형 Agent OS로
리서치 팀 구조 업그레이드

Anthropic financial-services repo의 핵심은 “멋진 샘플”이 아니라 plugin + managed-agent + quality gate 구조다. Research Desk는 이걸 회사 리포트, 시장 리서치, Quant 검증에 맞춰 가져온다.

Intel 리포트 예시 Monthly Momentum Desk Quant Bot Hub
MANAGED AGENT PATTERN
Vertical Skillsfinancial-analysis · equity-research · quant-risk
Named AgentsMarket Researcher · Earnings Reviewer · Publisher
Review Gatessource pack · red-team · publish/no-publish

20초 요약

WHAT WE COPY

구조를 베낀다: plugin → agent → gate

Anthropic repo처럼 금융 업무를 vertical skill bundle과 named workflow agent로 나누고, headless worker는 manifest/cookbook처럼 관리한다.

one sourcetwo surfaceshuman sign-off
WHAT WE DO NOT COPY

투자추천·자동거래 아님

모든 산출물은 관찰/검토용. Quant도 Validator + Risk 승인 전 live promotion 금지.

FIRST PASS

회사 리포트 품질 게이트에 즉시 적용

Source Pack, Financial Model, Company Analyst, Supply-chain, Valuation, Red-team, Publisher Reviewer를 명시 산출물로 분리한다.

DATA CONNECTORS

기관 데이터 우선, 공개 proxy는 라벨링

FactSet/CapIQ/Daloopa 같은 connector 철학을 가져오되, 지금은 SEC/DART/IR/Yahoo/Naver/Alpha/FMP 등 공개 proxy를 unverified로 표시한다.

Agent cookbook 변환표

Market ResearcherAnthropic: sector/theme primer. Research Desk: Daily Market + Cross-Ontology worker.Market Brief
Earnings ReviewerAnthropic: earnings call + filing → model update → note. Research Desk: EPS/guidance/source-pack 연결 상태 표시.Company Report
Coverage InitiatorAnthropic: 5-task initiation. Research Desk: Monthly Momentum deep dive의 institutional report skeleton.Monthly Momentum
Publisher ReviewerAnthropic guardrail: no distribution without review. Research Desk: raw draft, source caveat, mobile, link, base-path gate.Published Dashboard

품질 게이트 — 앞으로 리포트 상단에 더 명확히 보일 항목

  • Source Pack: IR/SEC/DART/earnings/industry/brokerage attempt.
  • Financial Model/Data Analyst: PER/PBR/revenue/margin/debt/ROE/EPS/consensus 상태.
  • Company Analyst: 사업모델, 수요 전파, 시장이 이미 믿는 것, 다음 catalyst.
  • Industry/Supply-chain Analyst: 병목, solver, 수혜 후보 lane.
  • Valuation/Strategy Analyst: Base/Upside/Downside, 가격 반영 여부, peer context.
  • Red-team Analyst: 반증 조건, bear case, contradiction map.
  • Publisher/Supervisory Analyst: publish/no-publish, 부족한 근거 표시.
