Samsung Electronics — Analyst Memo (Draft Replacement)

투자 추천이 아니다. 공개 Research Desk용 메모. 원문 초안을 대체하는 분석 프레임워크다.

1. 시장이 이미 믿는 것 (What's Priced In)

원문 초안: "AI server and general server demand, PC/mobile inventory normalization → DRAM/NAND price rise → memory ASP/bit shipment improvement → DS operating profit leverage. HBM is upside with NVIDIA/AMD qualification."

문제점: 이 문장은 사실상 시장 consensus를 그대로 복사한 것이다. 2024년 하반기부터 반복된 narrative이며, 현재 주가에는 이미 다음이 반영돼 있다:

  • DRAM/NAND price cycle bottom-out: 시장은 1Q25를 바닥으로 보고 있으며, spot price rebound은 이미 2개월간 뉴스로 소화됨
  • HBM3E qualification: NVIDIA H200/B200, AMD MI300X 관련 qualification은 이미 2024년 4Q~2025년 1Q에 priced in. "qualification 진행 중"은 새 정보가 아님
  • DS 부문 leverage: memory 가격 상승 → 고정비 희석 → 영업이익 급증. 이는 반도체 투자의 기본 공식이며, 시장이 모르는 내용이 아님

시장이 이미 믿고 있는 구체적 숫자 (consensus 기준):

  • 2025년 DRAM bit growth: +15~18% YoY
  • 2025년 NAND bit growth: +12~15% YoY
  • HBM revenue 비중: DS 전체의 15~20% (2025년 기준)
  • DS 영업이익률: 2Q25 15~18%, 2H25 25~30% (memory supercycle 가정)
  • MX/SDC는 "정상화" 수준으로만 반영 — turnaround narrative는 없음

결론: 원문 초안이 말하는 모든 것은 이미 시장에 알려져 있고, 주가에 반영돼 있다. 이 프레임으로는 alpha를 설명할 수 없다.

2. 돈이 들어오는 경로 (Capital Flow Path)

원문 초안의 결함: "demand → price → profit"은 회계 항목의 흐름이지, "돈이 들어오는 경로"가 아니다. 실제로 돈이 들어오는 경로는 더 복잡하다:

(A) 단기: HBM3E shipment ramp (2Q25~3Q25)

  • 경로: NVIDIA/AMD → Samsung HBM3E 12H shipment → DS Memory 매출 집중
  • 핵심: qualification은 끝났거나 끝나는 중. 이제 실제 shipment volume과 yield가 문제
  • 체크포인트: 2Q25 실적발표 시 HBM revenue 비중, bit shipment 가이던스

(B) 중기: Foundry/Logic turnaround (2H25~2026)

  • 경로: 3nm GAA yield 개선 → Qualcomm/AMD/NVIDIA 주문 회복 → DS Foundry 적자 축소
  • 핵심: 현재 DS Foundry는 1Q25 기준 적자 지속. turnaround는 HBM만큼 확실하지 않음
  • 체크포인트: 3nm yield trajectory, 2nm GAA tape-out 일정, 주요 고객 재배치 여부

(C) 구조적: MX/SDC turnaround (2025~2026)

  • 경로: Galaxy S25 AI 기능 → ASP 상승 + component cost down → MX margin 개선
  • 핵심: MX는 2024년 적자폭 축소했으나, 2025년 AI 기능이 실제로 premium mix를 끌어올리는지 미지수
  • 체크포인트: S25 출고가 분포, MX 영업이익률 분기 추이, SDC OLED panel 가격/물량

(D) 리스크 경로: Memory oversupply (2026년)

  • 경로: SK hynix + Micron HBM4 capacity 확대 → Samsung HBM market share 하락 → margin compression
  • 핵심: HBM은 현재 oligopoly지만, 2026년부터는 3파전 본격화
  • 체크포인트: HBM4 개발 속도, customer allocation 분포, CapEx 계획

3. 확인해야 할 숫자 (Numbers to Verify)

원문 초안은 "price rise", "ASP improvement" 같은 추상적 표현만 썼다. 실제로 확인해야 할 숫자는 다음과 같다:

| 항목 | 현재 consensus | 확인 방법 | 빈도 |

|---|---|---|---|

| DRAM spot price (DDR5 16Gb) | 상승 지속 중 | DRAMeXchange, TrendForce | 주간 |

| NAND spot price (512Gb TLC) | 상승 지속 중 | DRAMeXchange, TrendForce | 주간 |

| HBM3E yield | 70~80% (추정) | 공급망 체크, 실적콜 | 분기 |

| HBM3E shipment (Samsung) | 1Q25: ~30K wpm 추정 | 공급망, 실적발표 | 분기 |

| DS Memory 영업이익률 | 2Q25E: 15~18% | 실적발표 | 분기 |

| DS Foundry 영업이익률 | 1Q25: 적자 지속 | 실적발표 | 분기 |

| MX 영업이익률 | 1Q25: ~8% | 실적발표 | 분기 |

| SDC 영업이익률 | 1Q25: ~5% | 실적발표 | 분기 |

| CapEx (2025E) | ~$30B (memory 중심) | 실적발표, IR | 연간 |

| Free Cash Flow | 2025E: $10~15B | 실적발표 | 분기 |

| Net Cash Position | ~$60B | 실적발표 | 분기 |

| HBM4 개발 일정 | 2026년 샘플링 목표 | 공급망, 기술 컨퍼런스 | 월간 |

원문 초안이 빠뜨린 숫자:

  1. HBM yield: qualification은 통과했지만, yield가 60%인지 80%인지에 따라 margin이 완전히 달라진다
  2. Foundry turnaround timeline: DS Memory만으로는 그룹 전체 valuation을 설명할 수 없다
  3. MX/SDC 기여도: DS가 좋아져도 MX/SDC가 끌어내리면 주가는 sideways
  4. FCF/배당: Samsung은 배당주로도 본다. FCF trajectory가 중요하다

4. Bull Case (낙관 시나리오)

원문 초안은 bull case를 "HBM is upside" 한 문장으로 끝냈다. 이는 시나리오가 아니라 희망사항이다.

Bull Case 시나리오 (확률: 25~30%)

가정:

  1. HBM3E yield가 80% 이상 도달 → shipment volume 예상 상회
  2. 3nm GAA yield가 70% 이상 → Foundry 적자 2H25에 흑자전환
  3. Galaxy S25 AI 기능이 premium mix를 15%p 이상 끌어올림 → MX margin 12%+
  4. DRAM/NAND price rise가 2H25까지 지속 → DS Memory 영업이익률 30%+
  5. HBM4가 2026년 상반기에 NVIDIA/AMD 모두 qualification → 1년 이상 선점

결과:

  • 2025년 DS 영업이익: ₩35~40T (consensus: ₩28~32T)
  • 2025년 그룹 영업이익: ₩45~50T
  • FCF: $20B+
  • 주가: 현재 대비 +30~40% (memory supercycle + turnaround 복합)

핵심 촉매:

  • 2Q25 실적발표 (7월) — HBM revenue 비중, bit shipment 가이던스
  • 3Q25 실적발표 (10월) — DS Foundry 적자 축소 여부
  • Galaxy S25 판매량/ASP 데이터 (월간)

5. Bear Case (비관 시나리오)

원문 초안은 bear case를 완전히 생략했다. 이는 분석이 아니라 홍보다.

Bear Case 시나리오 (확률: 20~25%)

가정:

  1. HBM3E yield가 60% 이하에 머물러 → shipment volume 부진, margin 압박
  2. SK hynix가 HBM4에서 Samsung보다 6개월 이상 선도 → market share 하락
  3. DRAM/NAND price rise가 2Q25에 정점 → 2H25 하락 (oversupply)
  4. 3nm GAA yield 개선 지연 → Foundry 적자 2026년까지 지속
  5. MX premium mix 개선 미미 → MX margin 8% 이하 유지
  6. 미중 갈등/수출통제 확대 → China memory demand 급감

결과:

  • 2025년 DS 영업이익: ₩15~20T (consensus 하회)
  • 2025년 그룹 영업이익: ₩25~30T
  • FCF: $5B 이하
  • 주가: 현재 대비 -15~25% (memory cycle peak-out + turnaround 실패)

핵심 촉매:

  • HBM yield/shipment 루머 (공급망 체크)
  • DRAM spot price 하락 (주간 모니터링)
  • 미중 관계/수출통제 뉴스 (정치 리스크)
  • 2Q25 실적발표 — DS Memory margin이 consensus를 하회할 경우

6. 다음 촉매 (Next Catalysts)

원문 초안은 "HBM qualification"을 유일한 촉매로 언급했다. 이는 이미 진행 중이거나 끝난 이벤트다. 앞으로 다가올 실제 촉매는:

| 날짜 | 이벤트 | 중요도 | 체크할 것 |

|---|---|---|---|

| 2025년 7월 초 | 2Q25 실적발표 | 🔴 높음 | HBM revenue 비중, DS Memory/Foundry/MX/SDC 각 부문 영업이익, bit shipment 가이던스, CapEx 계획 |

| 2025년 7월 중 | HBM3E shipment 업데이트 | 🟡 중간 | 공급망 체크 — NVIDIA/AMD allocation 변화 |

| 2025년 8월 | Hot Chips / 기술 컨퍼런스 | 🟡 중간 | HBM4 로드맅, 3nm/2nm 기술 업데이트 |

| 2025년 9월 | Galaxy Z Fold7/Flip7 출시 | 🟡 중간 | 프리미엄 mix, MX margin 개선 여부 |

| 2025년 10월 초 | 3Q25 실적발표 | 🔴 높음 | DS Foundry 적자 축소 여부, MX turnaround 가속 여부 |

7. 내 판단의 약점 (Weaknesses in My Thesis)

원문 초안은 자기 반성이 전혀 없었다. 이 메모의 한계를 명시한다:

  1. HBM yield/shipment 데이터 접근성: Samsung은 HBM yield를 공개하지 않는다. 공급망 루머와 추정치에 의존하므로, 실제 수치는 2Q25 실적발표까지 알 수 없다. 이는 bull/bear case 모두의 근거가 불확실하다는 뜻이다.
  1. Foundry turnaround 불확실성: 3nm GAA yield 개선은 기술적 난제가 크다. Samsung이 이를 극복할 수 있을지, 아니면 TSMC에 고객을 더 잃을지는 기술 전문가의 판단이 필요하다. 본 메모는 이 점을 가정으로 처리하고 있다.
  1. MX/SDC 무관심: 원문 초안처럼 본 메모도 DS Memory/HBM에 비중을 두고 있다. 그러나 Samsung 그룹 주가는 DS만으로 결정되지 않는다. MX/SDC의 turnaround가 늦어지면 DS의 개선 효과가 상쇄될 수 있다. 이 메모는 MX/SDC에 대한 깊이 있는 분석을 제공하지 못한다.
  1. 지정학 리스크 과소평가: 미중 갈등, 수출통제, China memory 시장 의존도(약 30%)는 본 메모의 bull/bear case에 모두 영향을 미친다. 그러나 이 리스크를 정량화하기 어렵다.
  1. Memory cycle timing 불확실: DRAM/NAND price rise가 2Q25에 정점인지, 2H25까지 지속할지는 공급망 전문가의 판단이 필요하다. 본 메모는 "상승 지속 중"이라는 단순 관찰에 머물러 있다.
  1. 경쟁사 비교 부재: SK hynix, Micron, TSMC와의 상대적 competitive position을 분석하지 않았다. Samsung의 HBM4 timing, 3nm yield는 경쟁사 대비 어떤지가 더 중요하다.
