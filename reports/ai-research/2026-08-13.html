5분 훑기 1. AI4AI at Test-Time: Strong-to-Weak Capability Transfer via Harnesses

  • 위치: HF #3 · 👍 74 · Inference / Efficiency · Cheng Qian, Wenting Zhao · digest score 17
  • 쉽게 말하면: 큰 모델을 실제 서비스에서 더 싸고 빠르게 돌리기 위한 실행 최적화 논문이다.
  • 핵심 내용: Recent work on distillation transfers the capabilities of large models to smaller ones often by updating the latter's parameters, through teacher forcing, on-policy distillation, and related training-time methods. In this paper, we ask whether such transfer can instead occur at test time.
  • 핵심 용어: distillation = 증류: 큰 모델/기존 모델의 행동을 작은 모델이나 새 모델에 옮기는 학습; inference = 추론 실행: 학습이 끝난 모델을 실제 요청에 돌리는 단계
  • 내 판단: AI agent가 모델 개발·실험 과정을 실제 executable task로 얼마나 수행하는지 보는 MLE/AI4AI testbed 신호다. AI가 AI 개발 업무를 자동화하려면 benchmark 점수보다 실제 실험 설계·실행·디버깅 loop 완주율이 더 중요한 병목이기 때문이다.
  • 확인할 것: 실제 MLE task에서 실험 설정·코드 수정·실패 복구·결과 해석을 끝까지 수행하는지, benchmark가 toy task에 머물지 않는지.

5분 훑기 3. SkillZip: Contract-Preserving Graph Compression for Scalable Agent Skill Libraries

  • 위치: HF #5 · 👍 49 · RAG / Memory · Xingyu Tan, Xiaoyang Wang · digest score 17
  • 쉽게 말하면: LLM/agent가 검색 결과를 그대로 먹지 않고, 문서 묶음의 중복·충돌·보완성을 따져 RAG 근거 품질을 높이려는 retrieval/reranking 논문이다.
  • 핵심 내용: Large Language Models (LLMs) increasingly act as agents whose procedural knowledge is stored in reusable skill packages and loaded at inference time. As skill libraries grow, a central challenge is to expose the smallest sufficient executable context under a limited context budget.
  • 핵심 용어: retrieval/RAG = 검색/RAG: 외부 문서나 기억을 찾아 모델 답변에 붙이는 방식; agent = 에이전트: 모델이 도구를 쓰고 여러 단계를 실행해 일을 끝내는 구조; inference = 추론 실행: 학습이 끝난 모델을 실제 요청에 돌리는 단계
  • 내 판단: agent 답변의 상한이 retrieval set 품질에 묶인다는 점을 직접 겨냥한다. 단일 문서 점수보다 문서 묶음의 다양성·충돌·보완성을 보는 쪽이라 RAG/검색 품질 병목으로 읽는다. agent와 long-context workflow가 늘수록 답변 품질은 모델 자체보다 검색 근거 묶음의 품질·비용·감사 가능성에 막히기 때문이다.
  • 확인할 것: 정확도 개선이 단일 benchmark가 아니라 실제 RAG/search pipeline의 latency·중복 제거·상충 근거 처리까지 개선하는지.
