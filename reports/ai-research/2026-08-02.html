5분 훑기 1. Metis: Memory Foundation Model

  • 위치: HF #3 · 👍 256 · RAG / Memory · Zeyu Zhang, Ziliang Guo · digest score 18
  • 쉽게 말하면: agent가 대화기록·tool 출력·긴 prompt를 무작정 context에 쌓지 않고, 무엇을 기억/삭제/불러올지 lifecycle로 관리하려는 논문이다.
  • 핵심 내용: Recent advances in AI agents have increasingly internalized native capabilities into their underlying foundation models, giving rise to multimodal foundation models and large reasoning models. However, agent memory is still primarily implemented through external modules, leaving the native memory capability largely un…
  • 핵심 용어: agent = 에이전트: 모델이 도구를 쓰고 여러 단계를 실행해 일을 끝내는 구조; multimodal = 멀티모달: 텍스트뿐 아니라 이미지·영상·소리까지 함께 다루는 모델
  • 내 판단: agent memory를 단순 저장소/RAG 문제가 아니라 선별→구조화→저장소 선택→망각→현재 context 조립 lifecycle 문제로 재정의한다. 개인 agent의 비용·recall·provenance 병목과 직접 닿는다. agent 실패 원인이 reasoning 부족보다 context 과잉·recall 누락·token 비용으로 이동하고 있는지 확인할 수 있기 때문이다.
  • 확인할 것: context lifecycle 정책이 memory 저장·망각·provenance·현재 task relevance·token cost를 실제 agent workflow에서 함께 줄이는지.

  • 쉽게 말하면: 새 모델/방법을 제안하지만 우리 레이더 관점에서는 실제 병목과 연결되는지 먼저 확인해야 하는 논문이다.
  • 핵심 내용: We introduce PhiZero, a physical world model built around physical language, a compact discrete representation of world-state transitions. Existing physical world models typically predict future videos directly in pixel space, leaving the underlying world dynamics implicit within high-dimensional visual predictors.
  • 핵심 용어: post-training = 기본 학습 이후 보상·데이터·정렬로 능력을 보정하는 단계

  • 확인할 것: 코드/데이터/benchmark 공개 여부와 실제 사용 조건.
