On-Policy Distillation (OPD) — 연구 집대성

2020 ImitKD → 2026 ExOPD. 5년 만에 small/specialized model 학습의 indispensable post-training paradigm으로 정착.

>

본 페이지는 Samsung Research AI System Team의 본업 (GRPO · SR-470M · on-device · KV cache · multimodal) 관점에서 OPD 연구를 집대성. 학계 추세 + production adoption + 한국 적용 가능성을 한 곳에서 추적.

0. TL;DR (1분)

OPD = on-policy + distillation 결합 post-training.

  • On-policy: student가 자신이 생성한 sequence를 학습 (off-policy의 teacher-generated 학습과 반대)
  • Distillation: teacher의 dense per-token feedback 사용 (RL의 sparse sequence-level reward와 반대)

= RL의 state realism + Distillation의 dense supervision 결합.

왜 중요한가:

  1. Small/Specialized model 학습의 default: Qwen3, DeepSeek-V4, Gemma 2, MiMo-V2-Flash, Nemotron 모두 채택
  2. Compute 효율: Qwen3 결과를 Tinker로 재현 시 RL 대비 약 10× cheaper (Thinking Machines 보고)
  3. Train-inference mismatch 해결: student가 deployment에서 마주칠 distribution을 학습 시점에 미리 본 (= 누적 오차 회피)
  4. GRPO의 small model 실패 보완: GRPO 단독은 SLM에서 sparse reward로 불안정 → OPD가 dense supervision 보완

Samsung Research 관점:

  • GRPO + OPD 결합 (CoDistill-GRPO, SOD) = SR-470M 같은 SLM 학습에 직접 적용 가능
  • KV cache / inference cost 절감과 정합 (작은 model을 잘 학습하는 게 inference layer optimization과 직결)
  • on-device 채택 시 teacher (cloud) ↔ student (device) 학습 cycle 자연스러움

1. 정의 — Off-policy vs On-policy distillation

Off-policy distillation (전통적 KD)

  • 학습 데이터: teacher가 생성한 sequence (또는 정답 corpus)
  • 학습 방식: student가 teacher의 token distribution을 imitate
  • 문제: student가 deployment에서 자기 자신이 생성한 sequence를 보는데, 학습 시는 teacher's clean prefix만 봐서 exposure bias 발생. 누적 오차 (compounding errors) 발생.

On-policy distillation (OPD)

  • 학습 데이터: student가 생성한 sequence
  • 학습 방식: teacher가 student's trajectory의 각 token에서 dense per-token feedback (logit / KL) 제공
  • 효과: student가 deployment에서 보는 distribution을 학습 시 그대로 경험 → exposure bias 회피

핵심 insight (Thinking Machines 2025-10): "Sparse sequence-level reward is most useful for strong models that can explore and discover better behavior, while dense token-level teacher supervision is better suited for compressing that behavior into a smaller student."

→ GRPO 같은 RL은 frontier model에 유리, OPD는 SLM compression에 유리.

2. Timeline — 핵심 paper 16개 연대순

2020 — 시작

  • ImitKD (Lin et al., 2020) — on-policy distillation 시초. Student가 self-generated + fixed sequence 혼합 학습.

2023~2024 — Foundations

  • On-Policy Distillation of Language Models (Agarwal et al., arxiv 2306.13649, ICLR 2024) — Google DeepMind. GKD framework 정립.
  • GKD: Generalized Knowledge Distillation for Auto-regressive Sequence Models (Agarwal et al., 2024) — student-generated outputs 전용 학습, JSD divergence 기본값.
  • DistiLLM (Ko et al., ICML 2024) — Skew-KL divergence 도입 (Forward + Reverse 변형). 표준 KL의 gradient instability 해결.

2025 — 산업 적용 시작

  • DistiLLM-2 (Ko et al., arxiv 2503.07067) — Contrastive 확장. Student-generated outputs을 epoch마다 collect.
  • On LLM Knowledge Distillation: Forward KL vs Reverse KL (ICLR 2025 blog) — divergence 선택의 task-dependent 최적 분석.
  • Thinking Machines Lab blog (Mira Murati, 2025-10-27) — Tinker API로 Qwen3 재현. RL 대비 ~10× cheaper. Per-token reverse KL over short rollouts.
  • Rethinking LLM Distillation (2025) — Task reward 최대화 with hard KL constraint. Manual Lagrangian tuning 회피.
  • SOD: Step-wise On-policy Distillation for SLM Agents (arxiv 2605.07725) — Tool-use SLM agent에 step-wise OPD. GRPO removing → -2.4%, SOD removing → -17.7% (OPD가 더 critical).

2026 — Frontier 연구

  • A Survey of On-Policy Distillation for LLMs (arxiv 2604.00626) — comprehensive survey. 이 분야 1순위 reading.
  • ExOPD: Generalized On-Policy Distillation with Reward Extrapolation (arxiv 2602.12125) — OPD를 dense KL-constrained RL로 cast. Teacher-surpassing behavior 달성.
  • Asymmetric On-Policy Distillation (arxiv 2605.06387) — token-level exploitation vs imitation balance.
  • X-OPD: Cross-Modal OPD for Speech LLMs (arxiv 2603.24596) — multimodal 확장.
  • CORD: Audio-Text Reasoning Gap via OPD (arxiv 2601.16547) — cross-modal 응용.
  • Hindsight-Guided On-Policy Distillation (HF Daily Papers) — failure case에서 hindsight signal 활용.
  • Early Stopping Rollout for OPD (arxiv 2605.27028) — rollout 길이 최적화로 compute 절감.
  • Stable OPD through Adaptive Target Reformulation (arxiv 2601.07155) — 학습 안정성 개선.
  • CoDistill-GRPO (2026) — GRPO 단독은 SLM에서 실패하는 문제 해결. Large model이 small model의 OPD reward 제공. Qwen2.5-Math-1.5B에서 GRPO 대비 +6.0%, base 대비 +11.6% 향상.
  • Beyond GRPO and OPD: Sparse-to-Dense Reward Principle (arxiv 2605.12483) — sparse vs dense reward의 task-dependent 최적 분석.
  • Self-Supervised OPD for Reasoning (arxiv 2605.17497) — self-generated reward signal.
  • Scaling Reasoning via Relaxed OPD (arxiv 2603.11137) — long-CoT reasoning에 OPD relaxation.

5. Production Adoption — 누가 OPD를 채택했나

5.1 Frontier model 채택 (2025-2026)

  • Qwen3 (Alibaba) — OPD를 핵심 post-training으로. Thinking Machines blog 38회 인용.
  • DeepSeek-V4 — multi-teacher + curriculum + OPD 결합.
  • Gemma 2 (Google) — GKD framework 산업화.
  • MiMo-V2-Flash — small reasoning model OPD.
  • Nemotron (NVIDIA) — post-training 핵심.

5.2 OPD가 핵심 ingredient인 이유

  1. RL cost 절감 — Thinking Machines 보고: Qwen3 reasoning parity at ~10× cheaper than RL
  2. Small model 안정 학습 — GRPO 단독은 SLM에서 sparse reward로 불안정
  3. Train-inference distribution match — Exposure bias 해결
  4. Continuous learning — Mira Murati: "강한 domain 성능 + 지속적 학습 능력"

5.3 인프라 — Thinking Machines Tinker API

  • Tinker training API (https://thinkingmachines.ai/tinker)
  • OPD가 RL script 위 1-line 추가로 구현 가능
  • Open source cookbook: https://github.com/thinking-machines-lab/tinker-cookbook
  • 형준님 본업 (Samsung Research)에서 활용 가능성 검토 가치 ★★★★★

6. OPD vs GRPO — Samsung Research 본업 직접 연결

6.1 형준님 본업 컨텍스트

  • GRPO (Group Relative Policy Optimization) — Samsung Research RL 핵심 method
  • SR-470M — Samsung Research 470M parameter model
  • On-device — Galaxy AI / 차세대 device 적용

6.2 GRPO 단독의 SLM 실패 — OPD가 해결

Empirical finding (CoDistill-GRPO 2026):

  • Qwen2.5-Math-1.5B baseline GRPO → +0% over base
  • CoDistill-GRPO (GRPO + OPD reward from large model) → +11.6% over base, +6.0% over standard GRPO

SOD 2026 ablation:

  • GRPO 제거 → -2.4% performance drop
  • OPD 제거 → -17.7% drop (훨씬 critical)
  • = SLM에서 sparse reward 단독은 불안정, dense token-level teacher supervision이 primary guidance

6.3 SR-470M에 직접 적용 가능성

Pipeline 제안:

  1. Teacher: GPT-5 / Claude Opus / Gemini Ultra (frontier model) 사용
  2. Student: SR-470M (Samsung 자체)
  3. 학습: Tinker-style on-policy reverse KL over short rollouts
  4. 결합: GRPO sparse reward (frontier behavior exploration) + OPD dense reward (SR-470M compression)
  5. Domain: math / code / tool-use / Korean reasoning 등 specialized

예상 효과 (extrapolation from CoDistill-GRPO):

  • Baseline SR-470M 대비 +10~15% reasoning accuracy
  • RL 대비 ~10× compute 절감
  • On-device deployment에 적합한 size 유지

6.4 KV cache / inference cost와의 정합

  • Small student model = inference time + memory 절감 = KV cache 부담 ↓
  • OPD로 SLM 성능 압축 → on-device 채택 가속화
  • = 형준님 본업 thesis (small + cheap inference + on-device personal agent)와 직접 정렬

7. 한계 + 미래 연구 방향

7.1 현재 한계

  1. Reward hacking: OPD에서 student가 teacher distribution을 game할 위험. Hindsight-Guided OPD (2026)가 일부 해결.
  2. Catastrophic forgetting: specialized domain OPD 후 general capability 손실. Curriculum + multi-teacher 결합 필요.
  3. Teacher dependency: teacher 품질이 student ceiling 결정. ExOPD가 reward extrapolation으로 teacher 초과 시도.
  4. Compute cost: RL보다 싸지만 SFT보다는 비쌈. Early Stopping Rollout (2605.27028)가 rollout 길이 최적화.
  5. Long sequence: long-CoT reasoning에서 stable training 어려움. Stable OPD (2601.07155)가 일부 해결.

7.2 미래 연구 방향

  1. Multi-teacher OPD: 여러 teacher logit ensemble (DeepSeek-V4 패턴)
  2. Cross-modal OPD: speech, vision 확장 (X-OPD, CORD)
  3. Self-supervised OPD: external teacher 없이 self-generated reward (arxiv 2605.17497)
  4. Continuous OPD: deployment 후 user feedback으로 지속 학습
  5. Privacy-preserving OPD: on-device teacher 압축 후 federated OPD
  6. GRPO+OPD unified: sparse + dense reward 자동 balance (Beyond GRPO/OPD 2605.12483)
