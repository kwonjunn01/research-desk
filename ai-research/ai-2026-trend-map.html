AI 2026 Mid-Year Trend Map

2026년 6월 중간 점검. 어디로 자본·인재·연구가 몰리는가 + Samsung Research 본업과의 거리 + 자본 시장 연결.

>

자매 페이지: On-Policy Distillation 연구 집대성

0. TL;DR — 한 그림

              Capability
                  ↑
                  │
          [Reasoning + Agentic]
                  │
                  │
       Cost ←─────┼─────→ Personalization
                  │
                  │
           [Inference 효율]      [On-device]
                  │
                  ↓
            (병목 이동: Training → Inference)

5가지 macro shift (이것만 기억하면 됨):

  1. Pretraining → Test-time compute — Scaling law 변곡점, 추가 학습보다 추론 시 더 똑똑하게
  2. RL → OPD — Frontier RL의 cost 한계, OPD가 SLM 학습 default
  3. Single LLM → Agentic AI — 1-shot 답변에서 multi-step tool use / browser / orchestration
  4. Text → Multimodal Unified — VLA (Vision-Language-Action) + World models 본격
  5. Cloud → Hybrid → On-device — Personal agent + privacy + KV cache 최적화

시장 의미:

  • AI 자본의 새 bottleneck = Inference compute (training 대비 118× 증가 예상 by 2030, 75% 비중)
  • AI infra Q3 2026 자본 회전: GPU bound → Cooling/Power/Memory bound
  • 형준님 본업 (KV cache, SR-470M, on-device) = 트렌드 정중앙

1. 5 Macro Shifts — 깊은 분석

1.1 Pretraining → Test-time compute (Inference Scaling)

핵심 변화:

  • OpenAI o1/o3/o4-mini, DeepSeek R1, Gemini Thinking 모두 test-time scaling 채택
  • "더 큰 모델"이 아니라 "추론 시 더 오래 생각"으로 capability ↑
  • DeepSeek R1: frontier 대비 fraction cost로 reasoning parity

Insight (2025-2026):

  • 작은 모델 + 더 긴 reasoning > 큰 모델 + 짧은 답
  • 10B 파라미터 모델이 R1 reasoning 수준 도달 가능 (2026 말 예상)
  • Consumer-grade GPU에 reasoning model 배포 가능해짐

자본 시장 영향:

  • NVDA: Inference compute 폭증으로 training reduction 우려 상쇄 (+ side)
  • MU/SK하이닉스: HBM 수요는 training 외 inference에서도 강력 (+)
  • CRWV/CoreWeave 같은 inference cloud: 본격 수혜
  • MRVL Custom ASIC: Inference 전용 chip 수요 (long-term positive, 단 단기 멀티플 부담은 별개)

위험: Test-time scaling이 성숙기 진입 시 marginal capability gain 둔화 → frontier model 차별화 어려움

1.2 RL → OPD (On-Policy Distillation)

핵심 변화 (OPD 페이지 상세):

  • RL post-training의 cost / instability 한계
  • OPD가 RL 대비 ~10× cheaper (Thinking Machines)
  • Qwen3, DeepSeek-V4, Gemma 2, MiMo 모두 OPD 채택
  • GRPO + OPD 결합 (CoDistill-GRPO) — SLM 학습 SOTA

Samsung Research 직접 관련 ★★★★★

1.3 Single LLM → Agentic AI

핵심 변화:

  • 2026 Q2 변곡점: 모든 tool이 "agent" 카테고리로 racing
  • Parallel orchestration (다중 agent 동시 실행) 본격
  • Browser/computer use가 standard (Claude Code, Antigravity 2.0)

주요 player:

  • Claude Code (Anthropic) — Terminal-first, full filesystem access
  • Cursor — Full IDE, deep agent integration
  • Devin (Cognition) — 가장 autonomous, junior engineer 위임 모드
  • OpenAI Codex — Standalone cloud agent, desktop apps
  • Antigravity 2.0 (Google, 2026-05-19) — Multi-agent orchestration + Chromium browser + scheduled tasks + Go CLI + public SDK
  • Windsurf, Cline, Aider, OpenCode — niche players

Insight:

  • Single-agent → multi-agent → orchestrator (Q3 2026 다음 단계)
  • Agent가 "tool 만드는 agent"를 만드는 meta-level emergence
  • Browser/computer use가 commodity화 (2026년 핵심 차별화 요소 X)

자본 시장 영향:

  • Enterprise SaaS 위협 (Devin이 backoffice 자동화) — Salesforce, ServiceNow, Workday 검토 필요
  • Code generation tools consolidation — 5개로 압축 (Claude/Cursor/Devin/Codex/Antigravity)
  • API providers (Anthropic, OpenAI, Google) — agent layer competitive moat

1.4 Text → Multimodal Unified + World Models

핵심 변화:

  • VLA (Vision-Language-Action) = 로봇/AGI core architecture
  • World models 두 진영:
  • Pixel-space (Sora 2 / Genie 3 / Veo / Hunyuan-GameCraft): 영상 생성 = 세계 이해
  • Latent-space (V-JEPA / DINO-WM): 추상 represent + plan

Genie 2 (Google DeepMind):

  • 단일 image / text prompt → action-controllable 3D 환경
  • 키보드/마우스로 real-time interaction
  • 게임 엔진 + LLM 융합 패턴

Embodied AI:

  • Cosmos-Drive-Dreams, Gaia-2, DrivingWorld — autonomous driving simulation
  • ABot-PhysWorld — robotic manipulation with physics
  • Primitive Embodied World Models — scalable robotic learning

자본 시장 영향:

  • NVDA Omniverse + Cosmos models = robotics moat (+)
  • TSLA Optimus + FSD = VLA 직접 응용 (단 valuation premium 부담)
  • RKLB / KTOS Defense robotics 인접 (+)
  • Korea: 삼성 Bot (Ballie), LG CLOi 등 한국 robotics player

위험: World model evaluation 기준 부재, hype-driven 평가 위험

1.5 Cloud → On-device + Personal Agent

핵심 변화:

  • Apple Intelligence (3B on-device + cloud) 패턴 산업 표준화
  • Samsung Galaxy AI (SR-470M 추정) — Korean 에 특화 SLM
  • Google Pixel + Gemini Nano
  • Privacy preservation + cost 절감 + latency 개선

병목 이동:

  • Cloud GPU bound → On-device memory bound (KV cache)
  • 1M token context시 KV cache가 VRAM 70-90% 점유
  • MLA (Multi-head Latent Attention, DeepSeek) — KV cache 7-14× 압축
  • MQA/GQA (Grouped Query Attention) — Attention 헤드 sharing
  • FP8 KV cache — 메모리 반감 + sub-1% accuracy regression

자본 시장 영향:

  • 삼성전자 005930: Galaxy AI + SR-470M 본업, on-device leader
  • Apple AAPL: M-series chip + Apple Intelligence
  • Qualcomm QCOM: Snapdragon X / on-device AI 가속기
  • MU/SK하이닉스: On-device LPDDR + DRAM 수요 증가

한국 직접 수혜: Samsung Research 본업 SLM = 글로벌 트렌드 정중앙

2. Sub-trends 12개 (압축 분석)

2.1 Reasoning models (R1 family)

DeepSeek R1, Gemini Thinking, o-series. Reasoning RL post-training. Cheap reasoning model이 expensive base model 대체 진행.

2.2 Long context (1M+ tokens)

Gemini 3.1 Pro 1M, Claude Sonnet 4 1M. KV cache 최적화 (MLA, FP8, paged attention) 4-40× cost 감소.

2.3 MoE evolution

DeepSeek-V3 (671B/37B active, 256 experts, $5.6M training cost). Qwen3-235B (235B/22B, 128 experts, dual thinking mode). 2026 frontier model의 60%+ MoE.

2.4 VLA (Vision-Language-Action)

RT-2, OpenVLA, Pi 0. Robot foundation model 본격. Berkeley/Stanford/DeepMind 경쟁.

2.5 World models

Genie 2/3, Sora 2, V-JEPA, Cosmos. 게임 엔진 + 시뮬레이션 + 자율주행. Robotics infra의 base layer.

2.6 Code agents (Cursor/Claude Code/Devin)

2026 Q2 parallel orchestration. Enterprise SaaS 위협. Agent → Agent of Agents.

2.7 Robotics + Embodied

Figure 02, Optimus, Apptronik. VLA + Sim2Real + Foundation models 결합.

2.8 AI infrastructure

GPU/HBM 여전히 bottleneck. Liquid cooling (NVT/SPXC), Power (POWL/GEV), Backup (GNRC). Data center 자본 $725B 2026.

2.9 Scientific AI

AlphaFold 3, ESMFold, Microsoft Phi-MatChem. Drug discovery + materials science. Bayer / Recursion / Schrödinger 관련 stocks.

2.10 Open source competitive

Llama 4, Qwen 3, DeepSeek V3, Mistral Large 3, Gemma 2. Closed source 대비 6-12개월 lag 줄임.

2.11 Multi-LLM orchestration

Router (OpenRouter, Together) + Ensemble + Fallback. Single-model dependency 회피. 형준님 Hermes 직접 관련.

2.12 Safety / Alignment 2.0

Constitutional AI 2, Anthropic Sleeper agents, OpenAI superalignment 후속. Agentic AI 확산으로 alignment risk 증가.

3. 자본 시장 관점 — Wald frame 적용

3.1 "살아 돌아온 비행기" (이미 인지된 트렌드 수혜)

  • NVDA, AVGO, AMD — GPU/ASIC frontier
  • VRT, GEV, CEG, TLN — AI data center power/cooling
  • GOOGL, MSFT, META — Foundation model 직접 보유
  • PLTR, NOW — Enterprise AI distribution

→ 이 종목들은 이미 멀티플 폭등, marginal upside 작음

3.2 "돌아오지 못한" 또는 "분류 가려진" (Recognition gap 큰 트렌드)

  • NVT (cooling), SPXC, GNRC — AI infra 인접 forgotten
  • IRM — Storage REIT 가려진 data center
  • STX/WDC — AI cold storage (2027 sold out)
  • MRCY/LEU/BWXT — Defense + nuclear (AI 무관 macro hedge)
  • 삼성전자 005930 — On-device AI leader, valuation 한국 시장 견인
  • 네이버 035420 — HyperCLOVA + Korean reasoning
  • SK하이닉스 000660 — HBM 1위, MU 직접 비교 대상

4. Samsung Research 본업 관점 — 직접 / 인접 / 모니터링 3축

4.1 직접 (★★★★★) — 즉시 적용 가능

  • OPD + GRPO 결합 (CoDistill-GRPO, SOD) → SR-470M 학습
  • KV cache 최적화 (MLA, FP8, paged attention) → on-device inference
  • SLM compression (Qwen3, Gemma 2 패턴) → Galaxy AI
  • Test-time compute for SLM → reasoning capability 추가

4.2 인접 (★★★) — 6~12개월 내 도입 가능

  • VLA for Samsung robotics (Bot Care, Ballie)
  • Multimodal SLM — vision + Korean 통합
  • Agentic AI — Samsung 내부 코드/문서/메일 자동화
  • Multi-LLM orchestration — 형준님 Hermes 패턴 참고

4.3 모니터링 (★★) — 정보 우위 + 미래 trigger

  • Frontier reasoning models — o4, R2, Gemini 4 spec
  • World models — Genie 3, Sora 3 시나리오
  • Open source 경쟁 — Llama 5, Qwen 4 출시 시점
  • AI alignment — Anthropic Sleeper, OpenAI safety

4.4 형준님 본업 경쟁력 = OPD + KV cache + Korean SLM

이 3개 영역에서 형준님 본업이 글로벌 fronier에 매우 가까움. 차별화 keyword:

  • Korean reasoning OPD (영어 OPD literature는 풍부, Korean은 빈 공간)
  • On-device + KV cache compression
  • GRPO + OPD 결합 (Samsung 내부 IP 가능성)

5. Top 3 Picks for 형준님

이번 분기 가장 본업에 유용한 트렌드 3개:

1. OPD + GRPO 결합 — SR-470M 직접 적용 가능 ★★★★★

→ OPD 페이지 참고. Tinker cookbook + CoDistill-GRPO 패턴.

2. KV cache 최적화 (MLA, FP8) — On-device SLM 핵심

→ DeepSeek MLA 7-14× 압축, FP8 30-50% throughput. Galaxy AI inference cost 직접 영향.

3. Agentic AI orchestration — Multi-LLM 패턴

→ 형준님 본업에 직접 영향 X, 단 personal productivity 도구로 즉시 활용. Hermes + Claude 협업 모델 (현재 운영 중) = 정확히 이 패턴.
