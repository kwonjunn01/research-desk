AI Research Signal Map

AI research 항목을 논문/레포 나열이 아니라 능력 향상 → agent화 → orchestration/inference 병목 → edge 이동 → 신뢰성 리스크 흐름으로 보기 위한 공개 초안이다.

한눈에 보는 구조

flowchart LR PostTraining["Post-training"] -- improves --> Agentic["Agentic AI"] Orchestration["LLM Orchestration"] -- turns_models_into --> Agentic Inference["Inference Stack"] -- makes_feasible --> Agentic Inference -- enables --> OnDevice["On-device LLM"] OnDevice -- moves_workloads_to --> Edge["Edge AI"] Agentic -- requires --> Memory["Memory / RAG"] Memory -- introduces_risk --> RAGSecurity["RAG Security"] Orchestration -- uses_protocols_like --> MCP["MCP"]

읽는 순서

  1. 오늘 가장 뜨거운 topic은 어디인가?
  2. 그 topic이 어느 edge를 타고 다른 영역으로 전파되는가?
  3. hard signal인가, hype인가?
  4. production stack, 비용/latency, 재현성, adoption 증거가 있는가?
  5. weekly synthesis로 승격할 만한가?

Lens

  • Agent 실사용: demo를 넘어서 workflow/product/API로 가는가?
  • Post-training / RLVR: 모델 능력 향상이 reward/verifier/data 구조와 연결되는가?
  • Inference 비용/메모리: latency, throughput, KV cache, memory cost 병목을 건드리는가?
  • On-device / Edge: cloud inference를 대체하거나 edge workload를 새로 만드는가?
  • RAG / Memory 신뢰성: retrieval/memory가 정확성·보안 문제를 해결하는가, 아니면 attack surface를 키우는가?
