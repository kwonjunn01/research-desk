Agent AI Specialist Map

Agent AI를 하나의 buzzword로 보지 않고, 기술 stack → personal agent → 병목 → 매일 점검 질문으로 쪼개 보는 전문 리서치 지도.
Core Layers

9개 layer: model, planning, tool, memory, browser, runtime, eval, security, personal product

Bottlenecks

reliability, tool error, memory pollution, permission, eval gap, cost/latency

Daily Use

Daily AI Radar에 Agent AI Specialist Watch 섹션으로 연결

1. Stack overview

flowchart LR Model["Model & Reasoning"] --> Planning["Planning / Control"] Planning --> Tool["Tool Use / MCP"] Tool --> Runtime["Workflow Runtime"] Runtime --> Memory["Memory / RAG"] Memory --> Eval["Eval / Observability"] Eval --> Trust["Security / Trust"] Trust --> Product["Personal Agent Product"] Browser["Browser / Computer Use"] --> Tool Inference["Cost / Latency"] --> Product

2. Specialist lenses

Model & Reasoning

  • reasoning model이 실제 multi-step task success를 올리는가?
  • function/tool calling reliability가 좋아졌는가?
  • latency/cost가 daily agent UX를 허용하는가?

Planning & Control

  • goal decomposition이 장기 task에서 무너지지 않는가?
  • replanning과 human checkpoint가 있는가?
  • 계획 실패를 감지하는가?

Tool Use / MCP

  • tool discovery와 schema validation이 좋아졌는가?
  • MCP/tool protocol 생태계가 넓어지는가?
  • tool failure recovery가 있는가?

Memory / RAG

  • memory가 정확도를 올리는가, context pollution을 만드는가?
  • retrieved evidence trace가 있는가?
  • private memory permission이 명확한가?

Browser / Computer Use

  • 웹사이트 변화/UI drift에 견디는가?
  • 위험 action에 approval이 있는가?
  • multimodal/browser 비용이 UX를 망치지 않는가?

Runtime / Ops

  • state persistence와 resume이 되는가?
  • cron/background task 실패를 알리는가?
  • workflow version과 trace가 남는가?

Eval / Observability

  • benchmark가 실제 use-case와 맞는가?
  • task success/cost/latency를 추적하는가?
  • failure taxonomy가 있는가?

Security / Trust

  • prompt injection/tool abuse를 어떻게 막는가?
  • secret leakage와 permission boundary가 명확한가?
  • audit/revert가 가능한가?

Personal Agent Product

  • chatbot이 아니라 recurring workflow를 수행하는가?
  • email/calendar/browser/files/local memory와 연결되는가?
  • 사용자가 어디까지 맡길 수 있는가?

4. Daily Agent AI Specialist Watch

Daily AI Research Radar는 매일 아래 질문을 확인한다.

  1. 오늘 신호는 어느 layer에서 나왔는가?
  2. 실제 personal agent를 더 쓸모 있게 만드는가, 아니면 demo hype인가?
  3. 어떤 병목을 직접 건드리는가?
  4. 새 node/edge로 ontology에 추가해야 하는가?
  5. user-facing product 변화인가, infra/framework 변화인가?
  6. 내가 모르고 있던 unknown은 무엇인가?
  7. market/cross ontology로 이어질 edge가 있는가?
  8. prediction ledger에 올릴 만한 timing-gap claim인가?
