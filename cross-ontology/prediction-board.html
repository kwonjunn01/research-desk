예측별 확인 기준

PRED-20260505-001 — Short

  • 기술 쪽 확인: agent framework/repo release에서 memory, provenance, traceback, eval, audit 기능 반복 등장 여부.
  • 시장 쪽 확인: healthcare/legal/finance AI 뉴스에서 agent와 governance/security가 같이 묶이는지.
  • 무효화 조건: 다음 2주간 agent news가 UI/demo 중심으로만 반복되고 RAG trust/security evidence가 늘지 않음.

PRED-20260505-002 — Mid

  • 기술 쪽 확인: inference/memory efficiency research가 실제 serving cost language와 연결되는지.
  • 시장 쪽 확인: hyperscaler capex, data center, power/grid/cooling narrative가 inference/agent workload와 같이 언급되는지.
  • 무효화 조건: cloud providers가 capex guidance를 낮추면서 inference efficiency를 이유로 제시.

PRED-20260505-003 — Long

  • 기술 쪽 확인: local/on-device model deployment가 repo/demo가 아니라 product shipment로 이어지는지.
  • 시장 쪽 확인: robotics/device/semiconductor 뉴스에서 edge inference가 실제 제품/수요로 언급되는지.
  • 무효화 조건: edge AI가 demo/marketing에 머물고 cloud API가 latency/privacy concerns를 흡수.
