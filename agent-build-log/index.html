Agent Build Log

Hermes + Codex 기반 개인 Research Desk를 만드는 과정을 기록하는 공개 로그.

현재 만든 것

  • Obsidian/Markdown-first vault 구조
  • Daily AI Research Radar 자동 생성
  • Market Narrative Brief 자동 생성
  • Telegram delivery용 cron job
  • GitHub Pages 정적 사이트 배포
  • AI Research / Market Ontology overview-first 리포트 구조
  • 접히는 sidebar navigation: 큰 카테고리만 먼저 보이고 클릭하면 하위 항목 표시

앞으로 채울 글

  1. 왜 Notion-first가 아니라 Markdown/Obsidian-first인가
  2. Daily AI Research Radar 설계: source 수집 → ranking → topic heat → Telegram brief
  3. Market Narrative Brief 설계: watchlist → narrative → bottleneck radar
  4. GitHub Pages publishing loop: Markdown을 공개 HTML로 승격하는 방식
  5. 시각화 개선기: Mermaid graph, heatmap, ontology card, mobile-first layout

Build Map

flowchart LR Sources[Sources] --> Collect[Collectors] Collect --> MD[Markdown Vault] MD --> Reports[Daily Reports] Reports --> Telegram[Telegram Brief] Reports --> Public[GitHub Pages] MD --> Ontology[Ontology Maps] Ontology --> Public

다음 개선 후보

  • report 안의 raw graph를 Mermaid로 렌더링
  • topic heat를 표/목록이 아니라 card/heatmap 형태로 표시
  • 비어 있는 Weekly Review를 실제 주간 synthesis로 자동 초안화
  • Market watchlist를 기업별 card + supply chain graph로 표현
