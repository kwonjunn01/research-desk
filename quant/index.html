Quant Bot

OKX 실시간 public data 기반 BTC futures v2 paper trading과 전략/리스크/리포트/agent team을 분리해서 보는 Quant 운영 허브.

현재 상태

Paper Trading Running

OKX BTC-USDT-SWAP public data를 15초 간격으로 받아 300만원 기준 paper loop 실행 중

No Live Orders

private/trading API 미사용. live_orders_allowed=false. 현재 BUY/SELL은 paper signal

Quant Alert Group Only

전략 스위칭·BUY_WATCH·SELL_OR_EXIT_RISK·risk event만 Quant Alert group에 짧게 전송

1. 전략 Strategy

  • BTC Futures Grid v2 Daily Report — 2026-05-05
  • 베이스 전략: BTC futures grid/mean-reversion v2
  • 핵심 gate:
  • ADX < 18, range box 내부, squeeze 직후 아님 → BUY_WATCH 후보
  • ADX > 22 rising 또는 squeeze lower breakdown → 신규 매수 금지 / pending buy cancel
  • ATR 기반 grid spacing
  • doubling 금지

2. 모의 트레이딩 Daily 결과

  • 2026-05-05 Quant Daily Report

Daily Report에 포함되는 항목:

  • 오늘의 판단: BUY_WATCH / SELL_OR_EXIT_RISK / HOLD
  • 가격: last / mark / funding
  • gate state
  • paper 계정 equity / margin proxy / pending orders
  • 이벤트 분포
  • 최근 이벤트
  • 안전 체크

3. 리스크 Risk

현재 paper 단계의 안전 조건:

  • live trading API 사용 안 함
  • private account API 사용 안 함
  • OKX public data only
  • QUANT_BOT_ALERT_CHAT_ID가 group/supergroup이 아니면 알림 전송 중단
  • 동일 상태 반복 알림 dedup
  • heartbeat는 ledger에만 저장

Risk Bot이 우선권을 갖는 조건:

  • margin ratio proxy 초과
  • effective leverage cap 초과
  • stale data / API timeout
  • trend breakout / squeeze breakdown
  • pending buy cancel 필요

5. Rust Time-Series Forecast

Rust는 전체 봇 대체가 아니라 시계열 예측/특징 계산 코어로 쓴다.

Python: API 수집, orchestration, alert, report, promotion gate
Rust: fast features, regime/volatility/tail-risk forecast, walk-forward sweep

예측 목표:

  • 방향성 단일 예측보다 range/trend likelihood
  • volatility expansion probability
  • lower-band breakdown risk
  • tail move probability
  • funding/basis stress

Forecast 결과는 Strategy Bot의 보조 feature로만 사용한다. 단독 live 매수/매도 결정은 금지한다.
