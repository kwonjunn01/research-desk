1. 전략 Strategy

  • BTC Futures v2 Canonical Spec
  • BTC Futures Grid v2 Daily Report — 2026-05-05
  • Strategy Evolution Charter — simple but beautiful, spaghetti 방지, change review gate
  • Scenario Planning Playbook — black swan/위기 시나리오와 risk overlay
  • 베이스 전략: BTC futures grid/mean-reversion v2
  • 현재 paper 모델: OKX BTC-USDT-SWAP futures 20x display leverage
  • starter/probe: first_notional = capital × 20 × 0.5 / 31; 현재 2035 USDT 기준 약 656.45 USDT
  • 원본 골격 보존: 20x, 1-2-4-8-16, 1% 하락 추가매수, 평단 +0.5% 전체 익절
  • pending order는 다음 stage 1개만 둔다. stage2~5를 한 번에 전부 깔지 않는다.
  • 추가매수 gate만 보강: ADX/Squeeze/Margin 조건이 나쁘면 남은 물타기 주문을 취소/중단한다.
  • 상태 표기는 display leverage, account effective leverage, liquidation buffer를 분리해서 본다.
  • 핵심 gate:
  • ADX < 22, squeeze lower breakdown 없음, margin ratio < 50% → 남은 1-2-4-8-16 추가매수 허용
  • ADX > 25 rising 또는 squeeze lower breakdown 또는 margin ratio > 60% → 남은 매수 주문 취소
  • gate OFF여도 이미 진입한 포지션의 avg +0.5% TP는 계속 작동
  • 사자마자 팔지 않음: TP 미충족이면 보유

  • display leverage: 20x
  • account effective leverage: 약 0.3226x at stage 1
  • stage1 notional: 약 656.45 USDT
  • stage1 margin used: 약 32.82 USDT
  • liquidation buffer: 약 4.5% at entry
  • live trading API 사용 안 함
  • private account API 사용 안 함
  • OKX public data only
  • QUANT_BOT_ALERT_CHAT_ID가 group/supergroup이 아니면 알림 전송 중단
  • 동일 상태 반복 알림 dedup
  • heartbeat는 ledger에만 저장

Risk Bot이 우선권을 갖는 조건:

  • margin ratio proxy 초과
  • effective leverage cap 초과
  • stale data / API timeout
  • trend breakout / squeeze breakdown
  • pending buy cancel 필요

5. Rust Time-Series Forecast

Rust는 전체 봇 대체가 아니라 시계열 예측/특징 계산 코어로 쓴다.

Python: API 수집, orchestration, alert, report, promotion gate
Rust: fast features, regime/volatility/tail-risk forecast, walk-forward sweep

예측 목표:

  • 방향성 단일 예측보다 range/trend likelihood
  • volatility expansion probability
  • lower-band breakdown risk
  • tail move probability
  • funding/basis stress

Forecast 결과는 Strategy Bot의 보조 feature로만 사용한다. 단독 live 매수/매도 결정은 금지한다.
