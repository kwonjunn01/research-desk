Scenario Planning Playbook

블랙스완과 비정상 위험 상황을 Strategy Bot 내부에 덕지덕지 붙이지 않고, 별도 Scenario/Risk layer에서 관리한다. 중요한 기준은 차트만 보지 않고 맥락을 같이 보는 것이다.

Scenario Agent 역할

  • black swan / liquidity shock / funding shock / exchange outage 시나리오 생성
  • 사회상황, 기술 이슈, 규제/정책, 매크로 이벤트를 전략 맥락으로 변환
  • 각 시나리오의 failure mode와 대응 playbook 후보 작성
  • Risk Bot에 pause / no_new_stage / cancel_pending / reduce / kill_switch 후보 전달
  • Strategy Bot 본체의 복잡도 증가를 막음

기본 시나리오

Gap Down Shock

BTC 5분 -5% 또는 ATR x8 range. stage cascade와 청산 buffer 훼손 위험

Trend Acceleration

ADX rising + lower breakdown. 추가매수 금지, 기존 TP만 유지

Funding/Basis Shock

funding 급변/포지션 쏠림. 신규 stage 축소 또는 중단

External Event

FOMC/CPI/규제/해킹/거래소 이슈. 차트 외 맥락 기반 pause 검토

Context Sources

차트 지표는 결과이고, 맥락은 원인일 수 있다. Scenario Planning Agent는 아래 입력을 같이 본다.

  • Macro: FOMC, CPI, 금리, 달러, 유동성, 위험자산 선호
  • Regulation / Policy: SEC/ETF/거래소 규제, 국가별 정책 뉴스
  • Geopolitics / Social: 전쟁, 정치 이벤트, 사회적 panic/risk-off
  • Technology / Security: chain halt, exploit, bridge hack, custody 이슈
  • Crypto Market Structure: funding, basis, OI, liquidation cluster, ETF flow
  • Exchange Health: OKX stale data, mark-last divergence, API timeout
  • Narrative: BTC dominance, AI/tech sentiment, market rotation

Strategy Switch Inputs

시나리오 결과는 장세별 전략 스위치에 사용한다.

context + chart + risk state
→ scenario hypothesis
→ agent council review
→ strategy_mode decision
→ risk overlay

가능한 strategy mode:

  • ACTIVE_INFINITE_BUY_V2
  • 횡보/평균회귀 친화 장세
  • stage1/next-stage-only add-buy 허용
  • HOLD_EXISTING_NO_NEW_STAGE
  • 애매한 장세
  • 기존 포지션 TP 유지, 신규 추가매수 중단
  • ADD_BUY_OFF
  • 하락추세/브레이크다운 위험
  • pending buy 취소, TP 유지
  • EVENT_PAUSE
  • CPI/FOMC/규제/거래소/해킹 등 외부 이벤트
  • 신규 stage 금지, 수동 리뷰
  • DATA_NOT_READY
  • 데이터 품질 이상
  • 신규 intent 금지

Response Ladder

observe
→ hold_existing
→ no_new_stage
→ cancel_pending_buys
→ reduce_position_candidate
→ kill_switch
→ manual_review

Output Schema

{
  "scenario_id": "S_macro_event_risk",
  "severity": "medium_high",
  "context": ["FOMC within 24h", "funding abnormal", "OI rising"],
  "chart_evidence": ["ADX rising", "near lower band"],
  "strategy_mode": "HOLD_EXISTING_NO_NEW_STAGE",
  "recommended_action": "keep_tp_cancel_new_stage",
  "strategy_change": "none",
  "risk_overlay": "add_buy_gate_rest"
}

Strategy Integration Rule

Scenario output은 Strategy Bot을 직접 변경하지 않는다.

Scenario → Strategy Council → Risk overlay → Strategy intent gate

전략 변경으로 승격하려면:

scenario repeats
→ hypothesis
→ replay/backtest
→ validator
→ strategy candidate
→ paper validation
