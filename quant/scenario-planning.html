Scenario Planning Playbook

블랙스완과 비정상 위험 상황을 Strategy Bot 내부에 덕지덕지 붙이지 않고, 별도 Scenario/Risk layer에서 관리한다.

Scenario Agent 역할

  • black swan / liquidity shock / funding shock / exchange outage 시나리오 생성
  • 각 시나리오의 failure mode와 대응 playbook 후보 작성
  • Risk Bot에 pause / no_new_grid / cancel_pending / kill_switch 후보 전달
  • Strategy Bot 본체의 복잡도 증가를 막음

기본 시나리오

Gap Down Shock

BTC 5분 -5% 또는 ATR x8 range. grid cascade 위험

Trend Acceleration

ADX rising + lower breakdown. mean-reversion 금지

Funding/Basis Shock

funding 급변/포지션 쏠림. 신규 노출 축소

Exchange/API Degradation

stale data/timeout/last-mark divergence. data_not_ready

Response Ladder

observe
→ no_new_grid
→ cancel_pending_buys
→ reduce_position
→ kill_switch
→ manual_review

Output Schema

{
  "scenario_id": "S02_trend_acceleration",
  "severity": "high",
  "triggered": true,
  "evidence": ["ADX rising", "lower band breakdown"],
  "recommended_action": "no_new_grid",
  "strategy_change": "none",
  "risk_overlay": "gate_off"
}

Strategy Integration Rule

Scenario output은 Strategy Bot을 직접 변경하지 않는다.

Scenario → Risk overlay → Strategy intent gate

전략 변경으로 승격하려면:

scenario repeats → hypothesis → replay/backtest → validator → strategy candidate
