AI Quant Agent Team

Quant Bot은 “전략 하나가 모든 일을 하는 봇”이 아니라, 실제 퀀트팀처럼 역할을 나눈 agent system이다. 현재 기준 전략은 BTC Futures 무한매수법 v2이며, Strategy Bot은 원본 골격을 보존하고 Risk Bot은 추가매수만 통제한다.

Team Map

Strategy Bot

20x / 1-2-4-8-16 / 1% add-buy / avg+0.5% TP 원본 골격 유지

Risk Bot

ADX/Squeeze/Margin gate로 남은 추가매수만 중단 또는 재개

Paper Broker

stage fill, avg entry, next-stage-only pending, avg+0.5% TP를 paper로 시뮬레이션

Validator

fee/funding/slippage, OOS, black-swan replay 기준으로 승격 반박

역할

  • Portfolio Manager Agent
  • 전략용 서브계정 자본, pause/reduce/promote 후보 관리
  • high-watermark withdrawal 후보 제안
  • Research / Alpha Agent
  • 새 signal 후보와 실패 가설 생성
  • 원본 무한매수법 골격 변경은 직접 반영하지 않고 candidate로만 기록
  • Time-Series Forecast Agent
  • regime, volatility expansion, lower-band breakdown risk, tail-risk feature 생성
  • 단독 매수/매도 결정 권한 없음
  • Scenario Planning Agent

의사결정 흐름

flowchart LR Data[OKX public data] --> Quality[Data Quality Agent] Quality --> Forecast[Time-Series Forecast Agent] Quality --> Scenario[Scenario Planning Agent] Forecast --> Strategy[Strategy Bot] Scenario --> Risk[Risk Bot] Strategy --> Risk Risk --> Paper[Paper Broker] Paper --> Ledger[Ledger] Ledger --> Validator[Validator] Ledger --> Optimizer[Optimizer] Ledger --> Report[Reporting] Risk --> Alert[Quant Alert group]

Boundary Rules

Strategy Bot이 할 일:

  • 무한매수법 v2 원본 골격을 구현한다.
  • stage intent와 TP intent를 만든다.
  • 전략 변경 후보는 candidate ledger로만 남긴다.

Risk Bot이 할 일:

  • 남은 추가매수를 허용/중단한다.
  • margin proxy와 liquidation buffer를 감시한다.
  • stale data나 exchange degradation에서 신규 intent를 막는다.

하지 말아야 할 일:

  • Strategy Bot이 risk/margin/alert까지 전부 처리
  • Risk Bot이 원본 TP를 마음대로 trailing/split TP로 바꿈
  • 피드백 하나마다 if문을 계속 추가
  • stage2~5를 한 번에 전부 pending으로 깔기

Promotion Gate

candidate
→ shadow
→ paper_canary
→ paper_primary
→ live_candidate
→ live_approved

live_approved는 자동 승격 금지. 사용자 승인 필요.
