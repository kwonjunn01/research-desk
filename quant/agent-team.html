AI Quant Agent Team

실제 퀀트팀의 역할 분리를 차용하되, AI-agent가 더 잘하는 반복 검증·감시·리포팅·후보 생성 작업에 맞게 재구성한 팀 구조.

Team Map

PM Agent

전략 포트폴리오 방향, 자본 배분 후보, pause/reduce/promote 제안

Strategy Bot

BTC v2 베이스 전략을 BUY_WATCH / SELL_OR_EXIT_RISK / HOLD signal로 변환

Risk Bot

Strategy보다 우선. leverage, margin, stale data, breakout 시 reject/kill

Validator Bot

Optimizer 후보를 walk-forward/OOS/leakage/fee/funding/slippage 기준으로 반박

역할

  • Portfolio Manager Agent: 전체 운용 상태, 자본 배분 후보, pause/reduce/promote 제안.
  • Research / Alpha Agent: 새 signal 후보와 실패 가설 생성.
  • Time-Series Forecast Agent: Rust core로 regime/volatility/tail-risk 예측.
  • Strategy Bot: 베이스 전략 규칙을 signal/order intent로 변환. 주문 제출 권한 없음.
  • Risk Bot: 모든 order intent를 gate/reject/resize. Strategy보다 우선.
  • Execution / Paper Broker Agent: paper fill, TP, trailing, live later adapter.
  • Validator Agent: 후보의 overfit, leakage, OOS 안정성 검증.
  • Optimizer Agent: candidate config diff만 생성. live/risk cap 변경 금지.
  • Operations / Alert Agent: Quant Alert group only, event-driven concise alerts.
  • Reporting Agent: Daily/Weekly report와 homepage publish.

의사결정 흐름

flowchart LR Data[OKX public/live data] --> Quality[Data Quality Agent] Quality --> Forecast[Time-Series Forecast Agent] Forecast --> Strategy[Strategy Bot] Strategy --> Risk[Risk Bot] Risk --> Paper[Paper Broker / Execution] Paper --> Ledger[Ledger] Ledger --> Validator[Validator] Ledger --> Optimizer[Optimizer] Ledger --> Report[Reporting] Risk --> Alert[Quant Alert group]

Promotion Gate

candidate → shadow → paper_canary → paper_primary → live_candidate → live_approved

live_approved는 자동 승격 금지. 사용자 승인 필요.
