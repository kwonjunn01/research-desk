BTC Futures v2 — Canonical Spec

기준 전략: 20x BTC futures 무한매수법 v2. 원본 골격을 보존하고, 추가매수 중단 gate와 margin 방어만 추가한다. 기본 모드는 paper/backtest only; 실거래 자동주문은 별도 승인 전까지 비활성화한다.

1. 전략 철학

목표는 원본 무한매수법의 구조를 깨지 않으면서 청산 확률을 낮추는 것이다.

보존:

  • 20x futures
  • 5단계 doubling
  • 1% 하락 추가매수
  • 평단 +0.5% 익절

보강:

  • 첫 매수 사이즈 역산
  • 서브계정/자본 격리
  • ADX/Bollinger/Margin add-buy gate
  • Mark Price 기반 백테스트
  • fee/funding/slippage 반영

하지 않는 것:

  • 사자마자 팔기
  • split TP/trailing을 기본값으로 넣기
  • stage2~5를 한 번에 전부 pending으로 깔기
  • Strategy Bot 안에 예외 if문을 계속 덧붙이기

2. 자본 구조

  • 총자본 예시: 10,000 USDT
  • 전략용 서브계정만 운용
  • 메인 계정 reserve는 격리
  • 서브계정 내 cross margin
  • 손실 한도는 서브계정 잔고로 제한

현재 paper:

  • capital: 2035 USDT
  • exchange data: OKX public BTC-USDT-SWAP
  • private/trading API: 미사용
  • live orders: 금지

3. 첫 매수 사이즈

5단계 누적 배수:

1 + 2 + 4 + 8 + 16 = 31

공식:

first_buy_notional = capital × leverage × safety_buffer / 31

기본값:

leverage = 20
safety_buffer = 0.5

현재 2035 USDT paper 기준:

first_buy_notional = 2035 × 20 × 0.5 / 31
                   ≈ 656.45 USDT
stage1_margin      ≈ 32.82 USDT
account_eff_lev    ≈ 0.3226x at stage1

4. 진입 / 추가매수 / 익절

Stage ladder:

  • Stage 1: market starter buy, size 1x
  • Stage 2: Stage 1 기준 약 -1%, size 2x
  • Stage 3: 다음 -1%, size 4x
  • Stage 4: 다음 -1%, size 8x
  • Stage 5: 다음 -1%, size 16x

Pending order rule:

  • 한 번에 다음 stage 1개만 pending으로 둔다.
  • stage2~5를 전부 미리 깔지 않는다.
  • 다음 stage가 체결되면 buy_stage를 올리고, 조건이 맞을 때 다음 stage 1개를 다시 둔다.

Take profit:

take_profit_price = avg_entry × 1.005
  • TP 도달 시 전체 포지션 익절
  • TP 미충족이면 보유
  • gate OFF여도 TP는 계속 작동
  • 기본 전략에는 split TP/trailing stop 없음

5. Add-Buy Gate

게이트는 원본 진입/익절을 바꾸지 않는다. 남은 추가매수를 진행할지만 결정한다.

ON — 모두 충족:

  • ADX < 22
  • Bollinger squeeze lower breakdown 없음
  • margin ratio proxy < 50%

OFF — 하나라도 충족:

  • ADX > 25 and rising
  • Bollinger squeeze lower breakdown
  • margin ratio proxy > 60%

REST:

  • hard OFF는 아니지만 ON 조건도 부족한 중립 상태
  • 새 추가매수 주문을 적극적으로 깔지 않는다
  • 기존 포지션은 보유하고 TP를 기다린다

OFF 행동:

  • 남은 pending buy 취소
  • 추가매수 중단
  • 보유 포지션의 avg+0.5% TP 유지

6. Margin 방어

내부 단계:

  • 50%: 경고 / 다음 추가매수 skip 후보
  • 60%: 남은 pending buy 취소
  • 70%: 포지션 일부 축소 후보

이건 손절 전략이 아니라 더 이상 못 사게 막는 장치다.

7. Backtest Requirements

캔들 종가만 보는 백테스트 금지.

필수:

  • Mark Price 기준 liquidation/margin ratio 계산
  • round-trip fee
  • funding rate
  • partial fill simulation
  • slippage simulation
  • cross-margin equity tracking
  • pending order cancellation logic
  • stage별 fill/TP event ledger

8. Live Promotion Gate

live 승격 전 필수 조건:

  • 최소 며칠 이상의 public-data paper run
  • stage별 fill/TP/reject ledger 검증
  • fee/funding/slippage 포함 PnL 검증
  • black-swan scenario replay
  • Validator Agent 승인
  • Risk Bot 승인
  • 사용자 명시 승인

현재 상태:

live_orders_allowed = false
private_api_used = false
trading_api_used = false

9. Operating Summary

Start
→ stage1 first buy
→ if TP avg+0.5% hit: full close
→ else if gate ON: place next stage only
→ if next stage filled: update avg, increase stage
→ if gate OFF/REST: stop new add-buys, keep TP active
→ repeat until TP or max stage/risk intervention
