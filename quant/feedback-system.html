Quant Feedback System

목적: 전체 에이전트 팀과 시스템 판단에 대해 사용자가 피드백하고, 그 피드백을 전략/리스크/리포트 개선 후보로 연결한다.

피드백 대상

  • Strategy Bot: BUY_WATCH / SELL_OR_EXIT_RISK / HOLD 판단이 납득되는가?
  • Risk Bot: 너무 보수적인가, 너무 공격적인가?
  • Paper Broker Agent: stage fill, next-stage-only pending, avg+0.5% TP 시뮬레이션이 현실적인가?
  • Optimizer Agent: 제안 후보가 과최적화로 보이는가?
  • Validator Agent: reject 근거가 충분한가?
  • Reporting Agent: daily 결과가 찾기 쉽고 충분한가?
  • Alert Agent: 알림이 너무 많거나/적거나/산만한가?

피드백 레벨

approve      그대로 유지
question     근거 확인 필요
too_noisy    알림/리포트 과다
too_quiet    필요한 이벤트 누락
too_risky    리스크 과소평가
too_conservative  기회 과소진입
bug          동작 오류
feature      추가 기능 요청

저장 위치

~/quant-trading-bot/reports/feedback/feedback.jsonl
~/quant-trading-bot/reports/feedback/feedback_summary.md

운영 방식

  1. 사용자가 Telegram에서 짧게 피드백한다.
  2. Feedback Recorder가 JSONL에 저장한다.
  3. Reporting Agent가 Daily Report에 피드백 요약을 붙인다.
  4. Optimizer/Validator는 피드백을 직접 live 변경에 쓰지 않고 candidate 생성/검증 질문으로만 사용한다.

예시

agent=Alert Agent
level=too_noisy
target=HOLD 반복 알림
note=반복 상태는 보내지 말고 거래/전략 전환만 보내줘
agent=Strategy Bot
level=too_conservative
target=BUY_WATCH gate
note=횡보장인데 계속 REST면 ADX/Bollinger 조건을 리뷰해줘

안전 원칙

  • 사용자 피드백은 전략 변경 후보를 만들 수 있지만, live 변경을 자동 승인하지 않는다.
  • Risk cap 완화, leverage 증가, live enable은 수동 승인 없이는 불가.
  • rejected feedback/candidates도 남긴다.
